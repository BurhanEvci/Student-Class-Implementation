# Vehicle Class Implementation

A simple Python project demonstrating object-oriented programming and inheritance.

## Classes

- Vehicle: Stores brand and production year.
- Car: Inherits from Vehicle and stores the number of doors.
- Motorcycle: Inherits from Vehicle and stores engine capacity.

## Concepts

- Classes and Objects
- Inheritance
- Constructor
- Methods
- super() Function

## Usage

Run the program:

```bash
python main.py
```
